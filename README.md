# 🌱 AI 초등학교 수행평가 자동 채점 및 평어 생성 웹 프로그램

PyMuPDF 기반의 고해상도 페이지 이미지 변환과 Gemini Vision API의 멀티모달 인식 역량을 결합하여, **문서 양식이나 과목에 구애받지 않고 손글씨·분수 계산·꺾은선그래프·홍보물 포스터까지 정밀 채점**하고 **생활기록부용 150자 맞춤 평어**를 자동 생성하는 초등학교 교사용 웹 솔루션입니다.

---

## ✨ 핵심 기능 및 특징

### 1. 100% 비파괴 동적 구조화 (Zero Parsing Error)
- 기존 텍스트 추출 방식의 한계(표 깨짐, 순서 뒤섞임, 다단 인식 실패)를 극복하기 위해 **PyMuPDF로 모든 PDF 페이지를 이미지로 변환**합니다.
- Gemini Vision API를 통해 문서 양식이 제각각인 **수행평가 계획서**와 **교사별 평가 기준안**을 스마트하게 읽어 들여 표준 JSON 루브릭으로 동적 통합합니다.
- 계획서와 기준안의 단원명이 약간 달라도(예: '3. 의견을 모아서' vs '5. 의견이 드러나게 글을 써요') 성취기준과 평가요소를 기준으로 하나로 자동 매칭합니다.

### 2. 다중 페이지 시험지(뒷장) 자동 병합
- 학생 시험지 스캔본 중 인적사항(반/번호/이름) 칸이 없고 문항 번호가 이어지는 2페이지(뒷장) 시험지는 **직전 학생의 시험지로 자동 감지하여 병합**합니다.
- 1장과 2장을 한 번에 종합 평가하므로 앞·뒷장이 분리 채점되는 문제가 없습니다.
- 번호가 적혀 있지 않거나 판독이 어려운 경우 `미상_1`, `미상_2`로 자동 부여하여 번호 정렬 시 맨 뒤에 정돈됩니다.

### 3. 기준 기반 4단계 등급 & 150자 내외 생활기록부 평어 생성
- **4단계 성취수준 등급 산출**: 반드시 `매우잘함`, `잘함`, `보통`, `노력요함` 중 하나로 엄정하게 판정.
- **맞춤형 150자 평어(130~170자)**: 학생이 실제로 작성한 손글씨 답안, 수학 그림/그래프/서술 내용의 강점과 보완점을 균형 있게 반영하여 생기부/통지표 규격에 맞게 작성.
- **문체 옵션 제공**: 
  - 생활기록부 표준 개조식 (`~함.`, `~보임.`)
  - 정중한 서술형 (`~합니다.`, `~보입니다.`)

### 4. 파스텔 그린 테마 UI & 3D Pressable Button
- 초등학교 교실에 어울리는 따뜻하고 산뜻한 파스텔 그린 팔레트 적용.
- 클릭 시 부드럽게 눌리는 입체적인 **3D Pressable Button** 디자인.
- 실시간 진행 상태바 및 학생별 채점 현황 표시.

### 5. 화면 미리보기 & st.data_editor 실시간 수정 & 다중 시트 엑셀 다운로드
- 채점 완료 후 과목별 탭(`st.tabs`)으로 분리 표시.
- 교사가 화면에서 등급이나 평어를 직접 수정할 수 있는 `st.data_editor` 탑재.
- 학생의 번호 기준 정수 오름차순(1, 2, 3...)으로 정렬 (미상 학생은 맨 뒤).
- `openpyxl`을 활용하여 **과목별/단원별 별도 시트**로 분리된 엑셀 파일 생성.
  - 시트명 특수문자 제거 및 31자 제한 안전 처리.
  - 평가의견 자동 줄바꿈(`wrap_text=True`) 및 최적 열 너비 적용.

## 🚀 빠른 실행 방법

### 방법 1. 단독 실행 파일 (.exe)로 바로 실행 (추천! 별도 설치 및 폴더 불필요)
프로젝트 폴더 내 **`AI_수행평가_자동채점기.exe`** 파일 하나만 있으면 파이썬이나 기타 참조 폴더 없이도 단독 실행됩니다.
- 더블 클릭하여 실행하면 백그라운드 서버가 시작되고 **기본 웹 브라우저가 자동으로 열립니다.**
- 다른 PC나 USB 메모리에 이 `.exe` 파일 하나만 복사해서 사용하셔도 완벽하게 동작합니다.

### 방법 2. 원클릭 배치 파일 (`run.bat`)로 실행
`run.bat` 파일을 더블 클릭하여 파이썬 환경에서 즉시 실행할 수 있습니다.

### 방법 3. 명령 프롬프트 / 터미널에서 실행
```bash
# 디렉토리 이동
cd E:\AI개발\성적관리툴

# Streamlit 실행
C:\Python311\python.exe -m streamlit run app.py
```

브라우저가 열리면 사이드바에 **Gemini API Key**를 입력한 후 사용하시면 됩니다.

## 🛡️ 안정성 및 Rate Limit 방지 기능
- **지수 백오프(Exponential Backoff)** 및 자동 재시도(Retry) 알고리즘이 탑재되어 대량의 시험지 스캔본을 일괄 업로드하더라도 API 제한(429) 및 일시적 네트워크 오류를 안전하게 우회합니다.
- **Structured JSON Mode**를 강제 적용하여 응답 파싱 실패 가능성을 원천 차단했습니다.
