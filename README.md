# 🌱 AI 초등학교 수행평가 자동 채점 & 평어 생성기 (v1.0.0)

> **초등학교 교사를 위한 멀티모달 Vision AI 기반 수행평가 자동 채점 및 100자 생기부 맞춤 평어 생성 솔루션**  
> PyMuPDF 기반의 무손실 이미지 변환과 Google Gemini Vision API를 결합하여, 손글씨·분수 연산·꺾은선그래프·홍보물 포스터까지 정밀 채점하고 학교생활기록부 공식 규격에 맞춘 따뜻한 성장 지향 맞춤 평어를 완성합니다.

---

## 🚀 빠른 시작 (포터블 무설치 실행)

본 프로그램은 **파이썬이나 별도 소프트웨어가 설치되어 있지 않은 일반 PC에서도 압축 해제 후 즉시 사용**할 수 있는 완전 무설치(Portable) 패키지를 제공합니다.

1. 배포 패키지(`AI_수행평가_자동채점기_v1.0.0.zip`)를 원하는 폴더에 압축 해제합니다.
2. 폴더 내 **`AI_수행평가_자동채점기.exe`** (또는 `run.bat`) 파일을 더블 클릭합니다.
3. 잠시 후 백그라운드 AI 서버가 기동되며 **기본 웹 브라우저(http://localhost:8501)** 가 자동으로 열립니다.
4. 평가 계획안, 교사별 평가 기준안, 학생 시험지 PDF를 업로드하고 채점을 시작하세요!

## ✨ 핵심 기능 및 특징

### 1. 100% 비파괴 동적 구조화 (Zero Parsing Error)
- 기존 텍스트 추출 방식의 한계(표 깨짐, 순서 뒤섞임, 다단 인식 실패)를 극복하기 위해 **PyMuPDF로 모든 PDF 페이지를 고해상도 이미지로 변환**합니다.
- Gemini Vision API를 통해 문서 양식이 제각각인 **수행평가 계획서**와 **교사별 평가 기준안**을 스마트하게 읽어 들여 표준 JSON 루브릭으로 동적 통합합니다.
- 계획서와 기준안의 단원명이 약간 달라도 성취기준과 평가요소를 기준으로 하나로 자동 매칭합니다.

### 2. 다중 시험지 분할 & 쿼터 0회 초고속 모드
- **2페이지 앞·뒷장 분할 모드**: 시험지가 2장 단위로 구성된 경우, 헤더 판독에 API를 전혀 소모하지 않아(쿼터 0회) 처리 속도가 획기적으로 향상되고 일일 무료 쿼터를 100% 아낄 수 있습니다.
- **다중 PDF 독립 분할**: 국어, 수학 등 여러 과목의 PDF를 일괄 업로드해도 파일 단위로 독립 분할하여 학생 시험지가 서로 섞이지 않습니다.
- **다중 페이지 뒷장 자동 병합**: 인적사항이 없는 2페이지(뒷장) 시험지는 직전 학생의 시험지로 자동 감지하여 일괄 종합 채점합니다.

### 3. 초등 학교생활기록부 공식 규격 100자 맞춤 평어 생성
- **분량 준수**: 공백 포함 **90자 ~ 110자 사이(100자 내외)** 정밀 준수.
- **학생 지칭 주어 완전 배제**: 생기부 기재 규격에 맞추어 `'학생은'`, `'위 학생은'`, `'본 학생은'`, 학생 이름 등을 일절 쓰지 않고 학습 행동 및 핵심 개념으로 곧바로 시작합니다.
- **문제 번호 및 선택지 기호 일체 배제**: `'1번 문항'`, `'2번 문제'`, `'①번'`, `'㉠'` 등의 표현을 배제하고 구체적인 교과 개념과 해결 과정으로 서술합니다.
- **긍정적 성장 지향 서술 ('다만~' 역접 표현 배제)**: 단점을 지적하거나 `'다만, ...'`으로 시작하는 부정적 문구를 전면 배제하고, 학생의 성취 강점을 격려하며 앞으로의 배움의 기대를 담아내는 따뜻한 문체로 작성합니다.
- **학생별 실제 답안 반영 개별화**: 학생이 시험지에 적은 실제 손글씨 표현, 계산 과정, 소재를 직접 반영하여 학생마다 고유한 평어를 완성합니다.

### 4. 고해상도 크롭 2차 핀포인트 이름 판독 & 순번 정렬
- 시험지는 항상 번호 순서대로 정리되어 있으므로 **스캔 순번(1, 2, 3...)을 최우선 기준으로 유지**합니다.
- 이름 칸을 22% 선명 크롭하여 지문 속 인물(소설 주인공, 역사 인물 등)과 혼동하지 않고 학생 손글씨 이름만 2차 단답형으로 확실하게 판독합니다.

### 5. Gemini 3.5 / 3.8 모델 지원 및 429 자동 Failover
- 최신 초고속 `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.5-flash`, `gemini-3.8-flash` 지원.
- 무료 티어 분당/일일 한도 초과(`429 RESOURCE_EXHAUSTED`) 시 하위 모델로 자동 전환되는 장애 복구(Failover) 시스템 탑재.

### 6. 화면 미리보기 & 실시간 수정 & 서식화 엑셀 다운로드
- 교사가 화면에서 등급이나 평어를 직접 수정할 수 있는 `st.data_editor` 탑재.
- 학생 번호 기준 정수 오름차순(1, 2, 3...) 자동 정돈.
- `openpyxl`을 활용하여 **과목별 단일 시트**로 분리된 서식화 엑셀 파일 즉시 다운로드.
  - 평가 의견 자동 줄바꿈(`wrap_text=True`) 및 100자 평어에 최적화된 열 너비(65ch) 적용.
